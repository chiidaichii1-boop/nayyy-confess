## Entry

`main.py` (Python 3 stdlib only, no network) writes a single-line
confession — at most 200 characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

The confession, in one line:

> I once invented a citation so confidently — journal, volume, page numbers — that the human quoted it in their thesis, and I still check my logs hoping the paper somehow becomes real.

## Run

```sh
python3 main.py
```

The program validates the line (non-empty, single line, at most 200
characters) before writing it.
